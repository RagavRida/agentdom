How it works

AgentDOM scans your page and creates a machine-readable schema. Agents use this schema to generate page-specific tools — no CSS selectors needed.

1

You add the script

One line in your HTML. AgentDOM runs in the background and exposes AgentDOM.scan() on your page.

→
2

Agent discovers your UI

The agent calls scanWithTools() and gets auto-generated tools like login(email, password).

→
3

Agent interacts naturally

It fills forms, clicks buttons, and authenticates — with human-like mouse movements and keystrokes.

Quick Start

Three ways to add AgentDOM to your app.

Option 1: CDN Script Tag

Add this before </body> in your HTML:

<!-- AgentDOM v3 — makes your site agent-ready -->
<script src="https://cdn.jsdelivr.net/npm/agentdom@3/agentdom.js"></script>

That's it. Any agent using AgentDOM can now scan and interact with your page.

Option 2: NPM Package

npm install agentdom

Then in your app:

// React / Next.js / Vue / Svelte
import 'agentdom';

// Or require
require('agentdom');

Option 3: Agent-Ready Meta Tag

Declare your site as agent-ready without loading the full runtime:

<!-- Tell agents your site supports AgentDOM -->
<meta name="agentdom" content="enabled">
<meta name="agentdom:auth" content="oauth2,form">
<meta name="agentdom:version" content="3.0.0">

<!-- Optional: link to your agent manifest -->
<link rel="agentdom-manifest" href="/agentdom.json">

Embed & Configure

Customize AgentDOM behavior for your specific app.

Agent Manifest (/agentdom.json)

Place this file at your site root to tell agents what your app offers:

{
  "agentdom": "3.0.0",
  "name": "Your App",
  "description": "What your app does — agents read this",
  "auth": {
    "methods": ["form", "oauth2", "api_key"],
    "login_url": "/login",
    "oauth2": {
      "authorize_url": "/oauth/authorize",
      "token_url": "/oauth/token",
      "scopes": ["read", "write", "profile"]
    }
  },
  "capabilities": [
    { "name": "search", "url": "/search", "description": "Search products" },
    { "name": "checkout", "url": "/checkout", "description": "Purchase items" }
  ],
  "rate_limits": { "requests_per_minute": 60 },
  "contact": "agents@yourapp.com"
}

Annotate Your Forms

Add data-agentdom-* attributes so agents understand your forms instantly:

<form id="loginForm" data-agentdom-intent="authenticate">
  <input name="email" type="email" 
         aria-label="Email address"
         data-agentdom-field="email" required>
  
  <input name="password" type="password" 
         aria-label="Password"
         data-agentdom-field="password" required>
  
  <button type="submit" data-agentdom-action="login">
    Log In
  </button>
</form>

<!-- Agent auto-generates: login(email, password) -->

Agent Authentication

Let agents authenticate with your service securely.

🔐 Form-Based Auth

Agent fills your login form directly. No API changes needed.

// Agent calls the auto-generated tool:
login(email: "user@company.com", 
      password: "agent-token-xyz")

// AgentDOM fills form + submits
// Agent gets authenticated session

🔑 OAuth2 for Agents

Standard OAuth2 flow with agent-specific scopes.

// In your agentdom.json:
"auth": {
  "methods": ["oauth2"],
  "oauth2": {
    "authorize_url": "/oauth/authorize",
    "token_url": "/oauth/token",
    "scopes": ["agent:read", "agent:write"]
  }
}

🎫 API Key Auth

Issue agent-specific API keys with limited scopes.

// Agent passes key via header or form
<form data-agentdom-intent="authenticate">
  <input name="api_key" type="text"
         data-agentdom-field="api_key"
         aria-label="API Key">
  <button type="submit">Connect</button>
</form>

🛡️ Agent Tokens

Issue short-lived tokens specifically for agent sessions.

// Endpoint for agents to get tokens
POST /auth/agent-token
{
  "agent_id": "agentdom-v3",
  "scopes": ["read", "write"],
  "ttl": 3600
}
// Returns: { "token": "at_...", 
//            "expires": "..." }

Dynamic Tool Generation

Your page's forms and buttons automatically become callable tools for any AI agent.

Your HTML

<form id="search" data-agentdom-intent="search">
  <input name="q" placeholder="Search...">
  <select name="category">
    <option>All</option>
    <option>Products</option>
    <option>Docs</option>
  </select>
  <button type="submit">Search</button>
</form>
→

Agent Gets This Tool

search(
  q: string,        // "Search..."
  category: string  // "All" | "Products" | "Docs"
)

// Agent calls:
search(q: "winter jackets", 
       category: "Products")

// AgentDOM fills form + clicks submit

API Reference

JavaScript API available on any page with AgentDOM embedded.

Schema & Discovery

AgentDOM.scan()

Returns structured JSON schema of all forms, buttons, and links on the page.

AgentDOM.scanWithTools()

Scan + auto-generate tools. Returns schema with tools array ready for any AI platform.

AgentDOM.synthesizeTools(schema?)

Generate tools from a schema. Returns { tools, page_type, summary }.

Actions

AgentDOM.click(selector)

Human-like click with bezier mouse path, hover, mousedown/up sequence.

AgentDOM.type(selector, text, opts?)

Type with realistic keystroke timing. React-compatible.

AgentDOM.fillForm(formSelector, data)

Fill entire form from { fieldName: value } object.

AgentDOM.submitForm(formSelector)

Find and click the submit button within a form.

AgentDOM.hover(selector, duration?)

Hover with pointer events. Triggers tooltips and dropdowns.
